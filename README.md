# hackathon-website

Static site for the AI Game Lab hackathon: registration, demo uploads, and projects & voting (mock data).

## GitHub Pages

1. Repository **Settings** → **Pages**
2. **Build and deployment** → **Source:** Deploy from a branch
3. **Branch:** `main`, **Folder:** `/ (root)`
4. After deployment: `https://rschakenraadkrafton-jpg.github.io/hackathon-website/`

## Local preview

```bash
npx serve -l 5173
```
